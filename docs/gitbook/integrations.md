# Integrations

Bodhi plugs into the frameworks and telephony stacks you are probably already building on, so you can keep your orchestration and swap in Indian-language speech recognition.

| Integration                                                                | What it is                                                                                  |
| -------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| [Pipecat](pipecat.md)                                                      | Bodhi as the speech-to-text service in a [Pipecat](https://github.com/pipecat-ai/pipecat) voice agent pipeline |
| [FreeSWITCH module](https://github.com/navana-tech/bodhi-freeswitch-module) | Stream call audio to Bodhi from a FreeSWITCH dialplan                                       |

Building on something else? Bodhi's [streaming websocket API](/pages/FzOmeFuPs5VaDB7nePDp) is a few lines in any language, and we are happy to help — <support@navanatech.in>.
